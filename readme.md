# 🎵 Bhajan Music Hub

### A Modern Devotional Music Streaming Website

A fully responsive, modern, and visually appealing devotional music streaming website inspired by the user experience of leading music platforms while providing a unique spiritual experience. This project is built using **HTML5, CSS3, and Vanilla JavaScript** without any frameworks or libraries for the core functionality.

The website is designed to provide users with a beautiful and engaging platform where they can explore devotional songs, bhajans, spiritual podcasts, popular devotional artists, and daily darshan content through a clean and premium user interface.

The project emphasizes modern UI/UX design, responsive layouts, smooth animations, interactive music controls, and an organized structure that makes the code easy to understand and maintain.

---

# 📖 Project Overview

Bhajan Music Hub is a front-end web application created to offer a premium devotional music experience. The website combines modern web design principles with spiritual content to create an interface that is both elegant and user-friendly.

Unlike traditional music websites, this project focuses on devotional entertainment by presenting bhajans, artists, podcasts, and spiritual content in an attractive and organized way.

The application demonstrates how modern front-end technologies can be used to create an interactive music platform without relying on external JavaScript frameworks.

The project has been developed with the following goals:

- Build a professional-quality front-end project using only core web technologies.
- Practice responsive web design techniques.
- Create reusable and maintainable code.
- Deliver a smooth user experience with attractive animations.
- Organize content in a clean and structured layout.
- Showcase front-end development skills through a real-world project.

# 🚀 Installation

Follow these steps to set up the project on your local machine.

## 1. Clone the Repository

```bash
git clone https://github.com/your-username/bhajan-music-hub.git
```

## 2. Navigate to the Project Folder

```bash
cd bhajan-music-hub
```

## 3. Open the Project

Open the project using your preferred code editor such as:

- Visual Studio Code
- Sublime Text
- Notepad++
- WebStorm

## 4. Run the Website

Simply open the `index.html` file in your preferred web browser.

No additional installation or dependencies are required.

# ⚙️ Customization Guide

The project has been organized to make customization simple.

## Change Website Colors

Open:

```
style.css
```

Modify the CSS variables inside the `:root` selector.

---

## Replace Images

Replace the required images inside the `images/` folder while keeping the same file names.

---

## Add New Songs

1. Place the audio files inside the `audio/` folder.
2. Add the corresponding song information inside `script.js`.
3. Add the album artwork inside the appropriate image folder.

---

## Add New Artists

1. Add artist images inside:

```
images/artists/
```

2. Update the HTML with the new artist card.

---

## Add New Podcasts

1. Save podcast images inside:

```
images/podcasts/
```

2. Add a new podcast card in the HTML.

---

## Modify Website Content

Most of the website content can be updated directly from:

- `index.html`
- `script.js`

without changing the project structure.
